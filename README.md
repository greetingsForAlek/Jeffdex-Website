# THE JEFFDEX WEBSITE
The website that displays all of the characters from Jeff.

## How it works
Pretty simply, on the landing page, there is a grid displaying all of the characters. Select one of them to be brought to the page displaying all of the information about that character.

### Browsing Characters
To Browse Characters, you can click the search for a character button, which takes you to a page to search for all characters. You can optionally filter by Alignment or Canonicity, or just select either "All Characters" or "All Alignments" to just get all of the characters.
